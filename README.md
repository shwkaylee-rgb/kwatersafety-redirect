# kwatersafety-redirect

kwatersafety.com / www.kwatersafety.com 으로 들어온 접속을 대한수상안전협회 공식 홈페이지 https://kwasa.or.kr 로 보내는 리다이렉트 전용 GitHub Pages 저장소입니다.

- 옛 아임웹 경로(announcement, news_2, 24 …)는 kwasa.or.kr의 맞는 페이지로, 그 밖의 주소는 404.html을 통해 첫 화면으로 보냅니다.
- kwatersafety.com 의 메일(Google Workspace) DNS 레코드와는 무관합니다.
